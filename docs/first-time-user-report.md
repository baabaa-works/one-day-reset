# 陌生人首次使用體驗報告

- 日期：2026-10-13
- 方式：以手機尺寸（375×812）實際操作本機預覽版，從首頁一路走到快照結果、分享卡、完整工作台。過程中只看畫面，不查任何文件或程式碼。
- 測試限制：這是桌面瀏覽器模擬的手機畫面，沒有真實鍵盤彈出、沒有真的在 Threads / IG 內建瀏覽器開啟；「用說的」語音、實際下載圖片、實際分享、行事曆匯出都沒有按下去試。白天與夜晚階段只看了第一個畫面，沒有逐題作答。

## 一句話結論

**90 秒快照的前半段是順的，問題出在「寫完之後」和「進入完整工作台之後」。** 寫完三題，我拿到的是自己剛打的字原封不動排回來，接著是一整排分享按鈕；想再深入，就掉進一個長得像另一個產品、而且要我把剛才三題重寫一次的 28 題工作台。累的感覺不是來自題目多，而是來自「我付出了，但畫面沒有回應我」。

## 我一路走過的過程

### 1. 首頁：好懂，願意按

- 標題「最近很努力，卻不知道在往哪裡走？」有打到人，主按鈕「開始 90 秒快照」就在第一屏，「免登入、答案只留在你的手機」讓我放心。
- 往下滑是一張深綠色卡片，寫著「哪件小事，你想在這一週替自己留一點空間？」。我以為這是可以點的題目，結果只是分享卡預覽，旁邊配的是「分享給朋友」。我什麼都還沒做，就先被邀請分享，有點突兀。
- 右上角「完整工作台」我看不懂是什麼，也不知道跟快照的關係。

### 2. 第 1 題：選項很好，但一頁太長

- 五個標籤（一直很忙、很少休息…）是整個流程裡最輕鬆的一刻，點一下就有進展感。
- 但同一個畫面上方就有三段說明文字，全部都在告訴我「可以不用做」：「任何一題都可以跳過」「只當起手式，最多兩個，也可以略過」「（可選）」。底下還有「只給自己看 · 最多 500 字 · 可回上一題修改」「回答自動暫存於此瀏覽器；若儲存受限，離開前可複製回答」，再加上安心專線。一題的頁面高度約 1,325px，手機一屏只有 812px。
- 「下一題」按鈕在 1,025px 的位置，**第一屏看不到**；文字框在 677px，真實手機鍵盤一彈出來就會蓋住。
- 「已儲存在此瀏覽器。」是紅棕色字，第一眼以為是錯誤訊息。
- 底部三個按鈕並排：「先回首頁」「下一題」「跳過這一題」。下一題和跳過做的事幾乎一樣，我停下來想了一下差別在哪。

### 3. 第 2 題：範例幫倒忙

- 「三年後，某個普通的星期二」這題畫面感很好，是我最喜歡的一題。
- 範例收在一個要先點開的小三角形裡，很容易沒看到。
- 點了範例後，文字框被填入「我在＿＿醒來，接著＿＿，心裡覺得＿＿。」，游標在最後面。在手機上我得用手指精準點到每個底線、刪掉、再打字，重複三次。比自己從頭寫還累，我最後是全選刪掉重打。

### 4. 第 3 題：「三個問題」其實是五個欄位

- 這一題底下有三個輸入：這週的小事、身份句「我是會＿＿的人」、預計何時做（日期時間選擇器）。頁面高度 1,535px，是三題裡最長的。到這裡「90 秒」的承諾已經不成立了。
- 兩個欄位的提示都會誘導我打出重複的字，結果頁直接露餡：
  - 提示寫「這週我先＿＿。」，我照著寫「這週三晚上…」，結果頁顯示「**這週我先：這週**三晚上九點後…」
  - 身份句我填「晚上會關機休息」，結果頁大標變成「**我是會晚上會**關機休息的人」
- 我自己最重要的一句話，以文法怪怪的樣子變成結果頁最大的標題，有點尷尬。

### 5. 結果頁：最大的落差在這裡

- 標題「把下一步，留給這週的自己。」下面，就是我剛剛打的三段字照原樣排回來。沒有整理、沒有對照、沒有任何一句新的話。按鈕叫「整理我的快照」，但實際上沒有被整理的感覺。
- 我在第 1 題選的標籤「一直很忙」在結果頁**完全沒出現**，等於白點了。
- 緊接著是四個分享相關的控制項（傳給最近也很迷惘的朋友、複製邀請訊息＋連結、發到 Threads、換個口吻），然後才是選擇分享卡、修改快照、複製、下載、清除、帶到完整工作台。一個畫面十個動作，前四個都是要我幫忙推廣。
- 我剛寫的是「下班後沒有真的休息到」這種私人的事，下一秒最大的按鈕是「傳給最近也很迷惘的朋友」。情緒上接不起來。
- 我真正想要的下一步（提醒我這週三去做、或幾天後問我做了沒）在這個畫面找不到。因為我沒填時間，行事曆入口沒有出現，我也不知道原來可以有。

### 6. 分享卡頁：選項太多

- 這一頁高度約 1,958px，有十五個左右的控制項：兩種卡片內容、Threads / Instagram、兩種版型、四個邀請按鈕、存成圖片、複製連結、開啟手機分享、複製卡片文字＋連結，最後還有一段 IG 限動的操作說明。
- 我只想要「存圖」一件事，卻要讀完整頁才能確定按哪個。
- 值得肯定的是：預設卡片不含我的回答，這點說得很清楚，讓我安心。

### 7. 完整工作台：像是跳到另一個網站

- 配色從米白＋深綠變成亮萊姆綠＋深色頂欄，logo 樣式也不同，標語變成「停止空想。重新設計你的每一天。」語氣從溫柔變成命令。我第一反應是「我是不是點錯了」。
- 明明是第一次進來，卻有一個「從上次的地方繼續」按鈕，進度顯示 0%。我剛寫的三題沒有帶過來。（結果頁有一個小小的「帶到完整工作台」文字連結，但我是從右上角進來的，兩個入口行為不同，沒有人告訴我。）
- 總覽頁高度 2,410px，寫著 14 題＋6 次＋7 題，早上 15–30 分鐘、晚上 15–20 分鐘。剛做完「90 秒」的人看到這個數字會直接關掉。
- 進入第 1 題：文字框在 843px，**第一屏完全看不到可以打字的地方**，要先滑過頂欄、兩個標籤、大標題、進度條、說明、題目、思考提示。
- **第 1 題「那些被你習慣的微小不滿」和快照第 1 題幾乎是同一題**；第 12 題「三年後：你想過的普通週二」、第 13 題身份、第 14 題「這一週，先做哪一步」也分別就是快照的第 2、3 題。我剛寫過的東西要再寫一次，而且沒有預填。
- 早晨前 11 題連續都是偏沉重的題目（重複抱怨的事、不願承認的現實、五年後沒有改變、十年後關閉的選項、回望一生最可惜的空白、拖延的理由、迴避在保護什麼），到第 12 題才第一次問我想要什麼。每題都是一個空白大文字框，沒有選項、沒有任何回饋。我估計一般人會在第 3～5 題離開。
- 題號選擇器顯示「第 1 / 14 題」，但按鈕編號是 1–11、13、14、15，**少了 12、多了 15**；夜晚階段是 16–22。我搞不清楚自己在第幾題。
- 任務面板在沒填任何東西時高度約 3,925px，整頁都是「尚未填寫；先完成對應題目」「編輯第 18 題」「第 14 題」「第 17 題」這類我對不上的題號，底下還有下載 .md、備份 .json、匯入、列印、清空所有資料、儲存 / 複製 / 下載 / 列印六格卡、分享空白範本卡、行事曆提醒、寫回顧。「清空所有資料」就排在匯出按鈕旁邊。
- 白天階段第一眼看到的是「練習日期」「匯出 6 個行事曆提醒 (.ics)」「提醒 1 時間」「提問（可編輯）」「略過這個提醒，不加入行事曆」，像在填設定表單，不像在做練習。

## 缺少互動感的具體原因

1. **輸入之後沒有回應。** 整個流程唯一的回饋是「已儲存在此瀏覽器」。選標籤、寫完一題、完成三題，畫面都沒有因為我寫的內容而有任何不同。
2. **互動幾乎只有一種：空白文字框。** 快照第 1 題的標籤是唯一的例外，也是感覺最好的地方，但它在結果頁被丟掉了。
3. **三個答案之間沒有被連起來。** 題目設計本身是「現況 → 想要的畫面 → 這週一步」，這條線很好，但結果頁沒有把它呈現成一條線，只是三個方塊。
4. **結束點沒有屬於我的下一步。** 寫完之後產品問的是「要不要分享」，而不是「這週三要不要提醒你」。

## 建議調整（依優先順序）

### 第一優先：讓快照「寫完有收穫」

1. **結果頁改成有回應的畫面。** 不需要 AI：把三題排成「現在 → 想去的地方 → 這週一步」一條線，把選過的標籤顯示出來，加一個由我自己回答的收尾互動（例如「這一步有多小？」滑桿，或「這一步讓你更靠近那個星期二嗎？」是 / 還不確定）。重點是畫面要因為我的輸入而不同。
2. **結果頁第一個動作改成對我有用的事。** 「加入行事曆 / 這週提醒我」放最上面，分享收成一個按鈕、放到最下面，點了再展開口吻與平台選項。
3. **修掉重複字。** 身份句與行動句在組合前先去掉使用者重複打的開頭（「我是會」「會」「這週我先」「這週」），或把提示改成不會誘導重複的寫法。

### 第二優先：讓每一題在一屏內完成

4. **每題一屏：題目、輸入、下一步都在 812px 內。** 說明縮成一句；「可跳過」只在流程開頭講一次；儲存狀態改成輸入框旁的小勾勾（不要紅棕色）；安心專線與儲存說明移到首頁與結果頁，不必每題出現。
5. **下一步按鈕固定在畫面底部**，鍵盤彈出時也看得到。「跳過」併入「下一題」（空白時按鈕文字自動變成「先跳過」）。
6. **第 3 題拆開。** 小事是第 3 題；身份句與時間移到結果頁當作「想再加一點嗎？」的可選項，維持真正的三題。
7. **範例改成直接可用的整句或可點選的片語**，不要帶入需要手動刪除的＿＿。第 2、3 題也可以比照第 1 題給幾個可點的起手選項。

### 第三優先：把工作台接起來

8. **快照的三題自動帶進工作台對應題目**（第 1、12、13、14 題），並且不論從哪個入口進去行為都一致。進去後直接說「你已經完成 4 / 28，從第 2 題繼續」。
9. **統一視覺。** 兩邊用同一套配色、logo 和語氣，讓人知道還在同一個地方。
10. **新使用者不要看到「從上次的地方繼續」**；總覽頁不要一開始就亮出 28 題與總時數，改成「今天先做這 3 題，約 5 分鐘」這種分段。
11. **調整早晨題目的節奏。** 沉重題之間穿插想要的畫面，或至少每 3～4 題給一個小結（「你到目前為止寫下了…」），讓人有被接住的感覺。部分題目加上可點選的起手選項。
12. **修正題號**（1–14 連號），任務面板改用題目名稱而不是題號指路；面板在空白狀態時只顯示一句引導與一個按鈕，其他工具（匯出、列印、六格卡、回顧）等有內容後再出現；「清空所有資料」移開匯出按鈕並加確認。

### 可以晚一點做

13. 首頁的分享卡預覽換成「寫完會得到什麼」的結果示意，讓人在開始前就看到回報。
14. 分享卡頁預設只留「存成圖片」與「複製連結」，其餘收進「更多選項」。
15. 白天階段先呈現「現在停一下，回答這一題」，行事曆與時間設定收到次要位置。

## 做得好的地方（建議保留）

- 首頁標題與「免登入、答案只留在你的手機」，一看就懂、有信任感。
- 第 1 題的可點選標籤，是全流程互動感最好的設計。
- 第 2 題「三年後，某個普通的星期二」的提問角度具體又不嚇人。
- 三題的邏輯順序（現況 → 畫面 → 一小步）本身是通的。
- 分享卡預設不含個人回答，而且說明清楚。
- 整體文字語氣溫和，沒有成功學的壓迫感（工作台的「停止空想」除外）。

## 建議的下一步

先只改快照這條路（建議 1～7），因為這是陌生人唯一會走完的部分，而且改動集中在快照畫面。做完後用同樣方式再走一次，確認「寫完有收穫」成立，再處理工作台的銜接（建議 8～12）。

### web-design-guidelines 審查

這輪修掉的：

- 固定在底部的按鈕列可能蓋住鍵盤焦點所在的元件 → 加上 `scroll-padding-bottom`。
- 下拉選單與展開標題沒有焦點外框 → 補上。
- 裝飾用的箭頭會被讀成「↗One Day Reset」→ 加 `aria-hidden`。
- 沒有 `theme-color` → 補上，與頁面底色一致。
- 沒有設定點按反白色 → 設定。
- 選取狀態只靠顏色 → 選中的標籤、完成的進度都加上「✓」。
- 動畫沒有顧及 `prefers-reduced-motion` → 快照與完整版都會關掉動畫與轉場。
- 範例文字（placeholder）統一以「…」結尾。
- 彈出視窗捲到底會連動背景 → 加 `overscroll-behavior: contain`。

記錄下來、這輪沒修的：

- 瀏覽器的返回鍵不會回到上一題，會直接離開頁面（原本就如此；回答有暫存，回來可繼續）。
- 題目畫面的第一個標題是 `h2`，沒有 `h1`。
- 輸入框沒有 `name` 與 `autocomplete`。
- 進度條與按鈕底色的轉場不是只動 `transform`／`opacity`。
- 安心專線那段文字因為連結要維持 44px 點按高度，行距偏鬆。
- 完整版的題目卡、任務面板、白天階段沒有逐條審查。

### 還沒驗證到的限制

- 仍是桌面 Chrome 模擬手機尺寸：沒有真實鍵盤彈出，沒有 iOS Safari 的底部工具列與安全區域。
- 沒有在真正的 Threads／Instagram／LINE 內建瀏覽器裡開過；模擬只涵蓋較矮的視窗、User-Agent 與被封鎖的功能。
